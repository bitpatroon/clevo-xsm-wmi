────────────────────────────────────

Type 0x03, cmd 0xC1 (RGB COLOR) → Found 3 times
  Purpose: Set full RGB color per zone or globally
  Structure: [0x03, 0x00, 0xC1, <byte1>, <byte2>, <byte3>, <byte4>, 0x00]
  Bytes: Likely R,G,B + brightness/zone selector

Type 0x03, cmd 0xC2 (ZONE COLOR) → Found 35 times (heavily used!)
  Purpose: Set color per zone (left, mid, right, etc)
  Structure: [0x03, 0x00, 0xC2, <color_byte1>, <color_byte2>, 0x00, 0x00, 0x00]
  Bytes: Likely packed RGB or palette index

Type 0x03, cmd 0xC4 (MODE/EFFECT) → Found 5 times
  Purpose: Set lighting mode/effect
  Structure: [0x03, 0x00, 0xC4, <mode>, ...]
  Modes: Static, Wave, Breathe, Rainbow, Flash, etc.

  Purpose: Set brightness level
  Structure: [0x02, 0x00, 0xC6, <brightness_level>, ...]

────────────────────────────────────────────────────────────

WMI Communication Layer:
  • Init_WMI() → Initialize WMI interface
  • SetWMI() → Set single WMI parameter
  • SetWMIPackage() → Set WMI method package
  • SetWMIPackageEx() → Extended WMI package setter
  • GetWMI() → Get WMI parameter
  • GetWMIPackage() → Get WMI method package
  • GetWMIFlag() → Check WMI availability
  • SendMsg_WMI() → Send WMI message
  • GetMsg_WMI() → Receive WMI message
  • RW_WMIPackage() → Read-Write WMI package

RGB Control Functions:
  ▸ SetRGBAllColor(R, G, B) → Set entire keyboard to one color
  ▸ SetRGBLeftColor(R, G, B) → Left zone
  ▸ SetRGBMidColor(R, G, B) → Middle zone
  ▸ SetRGBRightColor(R, G, B) → Right zone
  ▸ SetRGBLogoColor(R, G, B) → Logo LED
  ▸ SetRGBLightBarColor(R, G, B) → Light bar (bottom)
  
  ▸ GetRGBAllColor() → Retrieve current color
  ▸ GetRGBLeftColor() → etc.
  
Zone Control (Alternative API for per-zone):
  ▸ SetZoneLeftColor(R, G, B)

Per-Key RGB (Advanced):

5. LINUX IMPLEMENTATION STRATEGY
─────────────────────────────────

We don't need to call the Windows WMI interface.
Instead, we need to:

  1. Use the DSDT ACPI WMBB method definition we already extracted
  2. Call acpi_evaluate_object() or wmi.evaluate_method() to invoke WMBB
  3. Pass the correct buffer with:
     - MethodId = 0x68 (for RGB color) or 0x67 (legacy) or 0x6A-0x6D
     - InBuffer with the RGB values
  4. The embedded EC controller handles the rest
